# dsh-attachment-history

[English](#english) | [简体中文](#简体中文)

## English

Version 1.2.0 for the pinned DSH 0.1.5-rc.2 suite. Collects authorized image occurrences from native V3 session events, retaining their original occurrence identity across compaction and child-session inheritance.

Build and test through the [suite workflow](../../deployment/windows/README.md#english).
Tests use synthetic sessions and blocked networking. No real conversation data is included.

## 简体中文

版本 1.2.0，用于固定 DSH 0.1.5-rc.2 组合。从原生 V3 会话事件收集有权访问的图片出现记录，在压缩与子会话继承后保留原始出现身份。

通过[suite 流程](../../deployment/windows/README.md#简体中文)构建与测试。
测试使用合成会话并阻断网络，不包含真实聊天数据。
