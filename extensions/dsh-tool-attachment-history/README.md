# dsh-tool-attachment-history

[English](#english) | [简体中文](#简体中文)

## English

Version 1.2.0 for the pinned DSH 0.1.5-rc.2 suite. Exposes explicit historical image recall using `{attachmentId, occurrence?}`. Checks the current route and attachment ownership before resolving image bytes. Mount once in each local preset.

Build and test through the [suite workflow](../../deployment/windows/README.md#english).
Tests use synthetic sessions and blocked networking. No real conversation data is included.

## 简体中文

版本 1.2.0，用于固定 DSH 0.1.5-rc.2 组合。通过 `{attachmentId, occurrence?}` 显式召回历史图片；读取图片前检查当前模型路由与附件归属。每个本地预设仅挂载一次。

通过[suite 流程](../../deployment/windows/README.md#简体中文)构建与测试。
测试使用合成会话并阻断网络，不包含真实聊天数据。
