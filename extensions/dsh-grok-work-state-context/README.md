# dsh-grok-work-state-context

[English](#english) | [简体中文](#简体中文)

## English

Version 1.2.0 for the pinned DSH 0.1.5-rc.2 suite. Renders current work state from native session projections and jobs. Mount only in Grok mode; the context is scoped and discarded when the composition is disposed.

Build and test through the [suite workflow](../../deployment/windows/README.md#english).
Tests use synthetic sessions and blocked networking. No real conversation data is included.

## 简体中文

版本 1.2.0，用于固定 DSH 0.1.5-rc.2 组合。从原生会话投影和任务生成当前工作状态。仅挂载于 Grok 模式；上下文限于当前作用域，并随组合释放。

通过[suite 流程](../../deployment/windows/README.md#简体中文)构建与测试。
测试使用合成会话并阻断网络，不包含真实聊天数据。
