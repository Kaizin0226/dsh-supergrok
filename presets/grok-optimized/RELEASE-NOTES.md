# Grok optimized 1.1.0 / Grok 优化预设 1.1.0

## English

Native DSH 0.2 preset derived from fixed official standard. The condensed
engineering persona adapts reviewed Grok Build 1.0.45 working principles.
Only identity, display text and persona differ; tools, model inheritance,
background jobs, compaction and permissions remain native DSH responsibilities.

Old image-recall and work-state dependencies are removed. No extra runtime,
network request, model selection or data migration is introduced.
Offline derivation/parity checks are integration evidence, not a model-quality claim.
Existing agent generations require native reload/restart to adopt a new preset;
historical prompts are not rewritten.

## 中文

从固定官方 standard 派生的 DSH 0.2 原生预设，精简工程 persona 参考已核对
Grok Build 1.0.45 原则。仅标识、展示及 persona 不同；
工具、模型继承、后台任务、压缩和权限仍由 DSH 原生机制负责。

移除旧图片召回和工作状态依赖，不增加运行时、网络请求、模型选择或数据迁移。
派生和一致性检查证明集成，不证明模型质量提升。
既有 Agent 须原生重新加载／重启才能使用新预设，不重写历史 prompt。
